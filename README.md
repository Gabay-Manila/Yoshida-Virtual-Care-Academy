# Yoshida Virtual Care Academy (YVCA) プロトタイプ

外国人介護人材（主にフィリピンの候補生・就労者）のための、**24時間いつでも学べるオンライン専門校**のプロトタイプです。
インストール不要・ビルド不要の **静的ファイルだけで動く PWA** です（サーバー側の処理は不要）。

> ⚠️ これは試作版（プロトタイプ）です。学習データは**利用者の端末内（localStorage）にのみ**保存されます。
> 修了バッジは本アカデミーのカリキュラム修了の証明であり、**国家資格・公的資格ではありません**。

## 1. できること

画面下のタブで、キャンパスの4つの施設を切り替えます。

| タブ | 施設 | 内容 |
|---|---|---|
| 📚 講義 | レクチャーホール | 全4章の学習＋章末ドリル（3問）。**3問全問正解で次の章が開く** |
| 🧑‍🏫 職員室 | ファシリティオフィス | AIせんせいとの質問対応（チャット）。関連する章へのリンクを自動表示 |
| 🎤 ラボ | トレーニングラボ | マイクで「声かけ」を練習し、その場で判定 |
| ☕ 自習室 | スタディラウンジ | Discordへの参加リンク、仲間の人数表示、自習タイマー |

あわせて、運営・指導員向けに **月次学習レポート（`report.html`）** を印刷・PDF保存できます。

### 全4章のカリキュラム

1. あいさつと声かけ
2. からだとバイタル
3. 移乗と移動
4. 皮膚と清潔介助（褥瘡・体位変換など）

各章は「今日のことば（タガログ語・英語の補足つき）」「会話スクリプト」「🔊読み上げ」「章末ドリル」で構成されています。

## 2. ファイル構成

```
/
├── index.html        アプリ本体（HTML・CSS・JavaScript が1ファイルに入っています）
├── curriculum.json   教材データ（章・ことば・ドリル問題）
├── report.html       月次学習レポート（印刷・PDF用の帳票）
├── sw.js             Service Worker（オフライン対応）
└── README.md         このファイル
```

**4つとも同じフォルダ（リポジトリのルート）に置いてください。**
外部ライブラリは使っていません（CDN不要）。

## 3. 公開（デプロイ）方法

> 重要：`curriculum.json` を読み込むため、**`index.html` をダブルクリックして開く（`file://`）と教材が表示されません。**
> 必ず `http(s)://` で配信されている状態で開いてください。

### A. GitHub Pages（無料・いちばん簡単）

1. このリポジトリに上記4ファイルをアップロード（コミット）します。
2. GitHub の **Settings → Pages** を開きます。
3. **Source** を `Deploy from a branch`、**Branch** を `main` / `/ (root)` にして **Save**。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

### B. Vercel

1. [vercel.com](https://vercel.com) で **Add New → Project** からこのリポジトリを選びます。
2. Framework Preset は **Other**、ビルド設定は空欄のまま **Deploy**。

### C. 自分のPCで試す

フォルダ内でどちらか1つを実行し、表示されたURL（例：`http://localhost:8000`）をブラウザで開きます。

```bash
python3 -m http.server 8000
# または
npx serve .
```

マイクは **HTTPS または localhost** でのみ使えます（GitHub Pages / Vercel はHTTPSなので問題ありません）。

### 更新したのに古い画面が出るとき

Service Worker が古いファイルを保持している場合があります。ブラウザで**強制再読み込み**（Ctrl+Shift+R / スマホは一度タブを閉じて開き直す）をしてください。
ファイルを大きく変更したときは、`sw.js` の先頭にある `CACHE='yvca-v3'` の数字を上げると確実です。

## 4. 受講生の使い方

### ① 講義（レクチャーホール）

1. 「📚 講義」タブで、開いている章（▶）をタップします。🔒は、前の章に合格すると開きます。
2. 「今日のことば」と「会話スクリプト」を読みます。🔊で日本語の読み上げを聞けます。
3. 「章末ドリルへ（3問）」をタップ。選択肢から答えを選びます（正解するとチャイムが鳴ります）。
4. **3問全問正解で合格** → 🏅バッジがつき、次の章が開きます。不合格なら「もう一度」で再挑戦できます（選択肢の並びは毎回変わります）。

### ② 職員室（AIせんせい）

1. 「🧑‍🏫 職員室」タブで、下の入力欄に質問を入れて「送信」。
2. 例：「褥瘡って何ですか？」「移乗のときの声かけは？」
3. 答えの下に **「📚 第◯章を見る」** のボタンが出たら、タップするとその章へ移動できます（まだ開いていない章は「未開放」と表示されます）。
4. 「返答を音声で読み上げる」にチェックを入れると、AIせんせいの返事を音声で聞けます。

**ビザ・在留資格・契約・給料・強い心の不調**などの相談では、AIせんせいは断定的な回答をせず、
「校長先生・担当コーディネーターに確認しますね」と案内し、例外アラートとして記録します。

> APIキーを設定しない場合は「モック応答モード」で動き、`褥瘡`・`移乗`・`バイタル`・`声かけ` などのキーワードに反応します。
> 自由な質問に答えさせたい場合は [5. Gemini API](#5-aiせんせいを本物のaiにするgemini-api) を設定してください。

### ③ ラボ（声かけ特訓）

1. 「🎤 ラボ」タブに課題が表示されます（例：「痛いところはありませんか？」と声かけしてください）。
2. 🔊で**お手本**を聞けます。
3. 大きな 🎙 ボタンを押して、日本語で話します（初回はマイクの許可が必要です）。
4. その場で文字起こしされ、**一致度**とフィードバックが出ます。

| 一致度 | 判定 |
|---|---|
| 85%以上 | ✅ 合格（チャイムが鳴る） |
| 60〜84% | 🟡 惜しい（お手本を表示） |
| 60%未満 | 🔴 もう一度（ヒントを表示） |

- 「痛いですか？」のように、より安心できる言い方がある場合は具体的なアドバイスが出ます。
- マイクが使えない・認識されないときは、**下の入力欄にテキストを入れて「判定」**でも練習できます。
- 合格すると「次の課題へ」が表示されます（全3課題）。

> 判定は**文字起こし結果の一致度**で行います。声のトーンや発音そのものは判定しません。

### ④ 自習室（スタディラウンジ）

- 「Discordで自習室に入る」から、Discordの自習室へ移動できます（リンクの設定は[8. カスタマイズ](#8-カスタマイズ箇所)）。
- 「いま勉強している仲間」の人数は、**試作では模擬の数字**です。
- 「⏱ 自習タイマー」：スタートして勉強し、「終了して記録」を押すと、経過時間が学習時間に加算されます（1分未満は記録されません）。

### ホーム画面に追加（アプリのように使う）

スマホのブラウザのメニューから「ホーム画面に追加」を選ぶと、アプリのように起動できます（ブラウザによって表示が異なります）。
一度開いたあとは、教材がオフラインでも表示されます（ただしAIせんせいのGemini接続には通信が必要です）。

## 5. AIせんせいを本物のAIにする（Gemini API）

1. [Google AI Studio](https://aistudio.google.com/) で Gemini の **APIキー**を発行します。
2. アプリの「🧑‍🏫 職員室」タブの一番下 **「⚙ 設定 / 校長室プレビュー」** を開きます。
3. 「Gemini APIキー」欄にキーを貼り付けて **保存**。
4. 画面上部の表示が「Gemini 2.5 Flash に接続中」に変われば完了です。

- 使用モデル：`gemini-2.5-flash`
- AIせんせいの性格・対話ルール（やさしい日本語、タガログ語・英語の補足、ビザ等は運営へ引き継ぎ）は、`index.html` 内の `SYS` に書かれています。
- 接続エラーのときは、エラー内容を表示したうえで、モック応答に切り替えて返答します。

> ⚠️ **セキュリティ注意**：APIキーは**その端末のブラウザ（localStorage）に保存**されます。
> 試作・個人確認用の仕組みです。**不特定多数に公開して運用する場合は、キーをアプリに入れず、Cloud Functions などのサーバー経由でGeminiを呼び出す構成に変更してください。**

## 6. 月次レポートの使い方（運営・指導員向け）

受入施設・送出機関へ提出できる、A4縦1枚の学習レポートです。

### 開き方

- アプリの「🧑‍🏫 職員室」→ 一番下の **「⚙ 設定 / 校長室プレビュー」** → **「📄 月次レポートを開く」**
- または、`report.html` を直接開きます。

> ⚠️ レポートは**受講生が学習した端末のブラウザ**に保存された記録から作ります。
> 受講生本人の端末で開くか、本人の端末から印刷・PDF化してください（複数の受講生をまとめて集計するには、クラウド保存が必要です。[12. 今後の予定](#12-今後の予定)）。

### 手順

1. 画面上部で **対象月** を選びます（初期値は今月）。
2. **学習者名**、**受入施設 / 送出機関ID**、**発行者** を入力します。
3. 内容を確認します。

| 項目 | 内容 |
|---|---|
| 月間学習時間 | 講義（合格時+5分）、ラボ合格（+1分）、自習タイマーの合計 |
| ログイン日数 | アプリを開いた日数 |
| 到達章 | その月にドリルを受けた最大の章 |
| 章末テスト平均正答率 | その月の全ドリルの正答数 ÷ 出題数 |
| 章末テスト結果 | 章ごとの受験回数・不合格回数・正答率・要復習の表示 |
| 弱点傾向 | 不合格が多かった単元の順位 |
| 指導コメント / 渡航前指導記録 | 集計から**雛形を自動作成**。自由に書き換えできます |

4. **指導コメント**欄を編集します。内容は月ごとに自動保存されます。「コメントを再生成」で雛形に戻せます。
5. **「🖨 印刷 / PDF保存」** を押します。印刷画面で「PDFとして保存」を選ぶと、入力欄などを除いた帳票だけがPDFになります。

### サンプルを見たいとき

画面上部の **「サンプル表示」** にチェックを入れると、記録がなくても見本のデータで帳票を確認できます（実際のデータは変更されません）。

### レポートに載せない情報

AIせんせいへの相談内容（ビザ・体調などの例外アラート）は、**受入法人に渡す帳票には載せません。**

> 学習時間は、レポート機能を追加したバージョン以降の記録から集計されます。それ以前の合計時間は月別に分けられないため含まれません。

## 7. 教材を編集する（curriculum.json）

章・ことば・ドリル問題は **`curriculum.json` を書き換えるだけ**で変更できます（`index.html` の修正は不要）。

### 形式

```json
{
  "version": 1,
  "chapters": [
    {
      "id": 1,
      "t": "あいさつと声かけ",
      "w": [
        ["おはようございます", "Magandang umaga po"],
        ["失礼します", "Excuse me / Paumanhin po"]
      ],
      "s": "「おはようございます。今日は体調はいかがですか？」",
      "q": [
        {
          "q": "部屋に入るときの言葉は？",
          "o": ["失礼します", "さようなら", "いただきます"]
        }
      ]
    }
  ]
}
```

| キー | 意味 |
|---|---|
| `id` | 章番号。**1から順番に、配列の並び順と一致させてください**（1, 2, 3, …） |
| `t` | 章のタイトル |
| `w` | 「今日のことば」。`["日本語", "タガログ語や英語の説明"]` の組を並べる |
| `s` | 会話スクリプト（🔊で読み上げされます） |
| `q` | 章末ドリル。1問ごとに `q`（問題文）と `o`（選択肢） |

### ルール

- **`o`（選択肢）の先頭（1番目）が必ず「正解」** です。表示するときに自動でシャッフルされるので、先頭が正解でも利用者にはわかりません。
- 合格条件は「その章の全問正解」です。問題数は章ごとに自由に増減できます（3問が基準です）。
- 章を足すときは、`id` を次の番号にして、配列の最後に追加します。
- JSONの書き方（カンマ・引用符）を間違えるとアプリが起動しないので、編集後は [JSON検証ツール](https://jsonlint.com/) などで確認すると安心です。
- 更新を反映するには、デプロイ後に強制再読み込みをしてください。

### 「職員室」から章へのリンクを増やす

AIせんせいの答えに付く「📚 第◯章を見る」ボタンは、`index.html` 内の **`KB`**（キーワード → 章番号の対応表）で決まります。新しい章を足したときは、そのキーワードも `KB` に追加してください。

## 8. カスタマイズ箇所

| やりたいこと | 場所 |
|---|---|
| Discordの自習室リンクを設定 | `index.html` の `const DISCORD='https://discord.com/';` を招待リンクに変更 |
| AIせんせいの性格・対話ルール | `index.html` の `SYS` |
| ビザ・メンタル不調などの検知ワード | `index.html` の `EXC`（正規表現） |
| 検知時の案内メッセージ | `index.html` の `ESC` |
| モック応答（キーワード回答） | `index.html` の `KB` |
| ラボの課題・正解表現・注意コメント | `index.html` の `TASKS`（`ok`=正解表現、`ng`=言い方のアドバイス、`hint`=ヒント） |
| ラボの合格ライン（85% / 60%） | `index.html` の `judge` 関数 |
| 発行者の初期表示 | `report.html` の `rep` の `iss` |

## 9. データの保存先とプライバシー

学習データは**サーバーには送信されず、その端末のブラウザ（localStorage）に保存**されます。

| キー | 内容 |
|---|---|
| `yvca` | 表示名、現在の章、バッジ、学習時間、学習ログ（最大2,000件）、ログイン日、例外アラート、APIキー |
| `yvca_cur` | `curriculum.json` のコピー（オフライン用） |
| `yvca_report` | レポートの入力内容と指導コメント |

- ブラウザのデータを消去すると、学習記録も消えます。別の端末・別のブラウザとは共有されません。
- AIせんせいに Gemini を使う場合、**質問文は Google の Gemini API に送信されます**。個人情報（パスポート番号など）は入力しないよう、受講生に案内してください。

## 11. 既知の制限

- 学習データは端末内のみで、**複数の受講生をまとめて見ることはまだできません。**
- 例外アラートは**端末内に記録されるだけ**で、校長先生へのメール／Slack／LINE通知はまだありません。
- 「いま勉強している仲間」の人数は**模擬の数字**です。
- 音声認識の精度は、ブラウザ・周囲の雑音・発音によって変わります。
- アプリのインストール用の設定ファイルはコードで生成しているため、ブラウザによっては「ホーム画面に追加」の挙動が異なります。
- 教材は4章・各3問の試作内容です。実運用には教材の追加と監修が必要です。

## 12. 今後の予定

1. **Firestore 連携**：学習ログ・進捗のクラウド保存（`students` / `study_logs` / `exceptions_alert`）と、受講生をまたいだ集計

5. 教材の拡充（国家試験対策、トレーニングラボの課題追加）
